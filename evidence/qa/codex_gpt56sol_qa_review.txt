   16: ## Crypto stack summary
   17: 
   18: | Layer | Preimage | Serialization | Digest/Sig | Encoding |
   19: |---|---|---|---|---|
   20: | Entry hash | `{sequence, entry, previous_hash, authorized_by?}` | RFC 8785 JCS | SHA-256 | lowercase hex |
   21: | Agent signature | the entry_hash **hex string** (64 ASCII bytes, UTF-8) | raw | Ed25519 | base64 |
   22: | Merkle leaf | `0x00 â€– raw32(entry_hash)` | raw bytes | SHA-256 | hex |
   23: | Merkle node | `0x01 â€– left32 â€– right32` | raw bytes | SHA-256 | hex |
   24: | Operator seal | integrity block (below) | RFC 8785 JCS | Ed25519 | base64 |
   25: | Contract hash | `intent_contract` object | RFC 8785 JCS | SHA-256 | lowercase hex |
   26: | Manifest seal | manifest minus `operator_signature` | RFC 8785 JCS | Ed25519 | base64 |
   27: | Manifest `files{}` | exact file bytes as written (NOT JCS) | â€” | SHA-256 | lowercase hex |
   28: 
   29: Keys: public = base64 of SPKI **PEM text** (double-encoded); private = PKCS#8
   30: PEM. Fingerprint = `"sha256:" + hex(SHA256(raw 32-byte public key))`.
   31: 
   32: ## Entry hash (Â§4.1)
   33: 
   34: `entry_hash(n) = sha256_hex( JCS({ "sequence": n, "entry": <full nested typed
   35: entry>, "previous_hash": <prev entry_hash | "" for n=0>, "authorized_by":
   36: <AuthorizationRef â€” ONLY when an operation-scoped override exists> }) )`
   37: 
   38: - `entry` = the complete typed object exactly as stored in `entries.ndjson`
   39:   (with `type`, `entry_id`, `timestamp`, every type-specific field) â€” NOT the
   40:   ChainedEntry wrapper, NOT a projection.
   41: - `authorized_by` omitted entirely when absent (no-override entries hash as the
   42:   3-member object).
   43: - Verification: seq dense ascending from 0; `previous_hash` equals prior
   44:   `entry_hash`; recompute and compare.
   45: 
   46: ## Merkle root (Â§4.2.1, F9)
   47: 
   48: leaf = `SHA256(0x00 â€– bytes.fromhex(entry_hash))`; node = `SHA256(0x01 â€– L â€– R)`;
   49: odd node carried up UNCHANGED (never duplicated); empty log â†’ `""`.
   50: Pinned: single-leaf root equals leaf (probe line 2).
   51: 
   52: ## Operator seal (Â§4.2, F6)
   53: 
   54: Ed25519 over UTF-8 bytes of `JCS({ "session_id": ..., "merkle_root": ...,
   55: "entry_count": <int>, "closed_at": ..., "schema_version": 2,
   56: "agent_fingerprint": "sha256:<hex>", "canonicalization": "RFC8785" })`.
   57: Pinned empirically (probe line 4): "RFC8785" exactly â€” note the record's
   58: integrity_attestation *displays* `canonicalization: "jcs"`; the *signed* value
   59: is `"RFC8785"`. `signed_at` is informational, NOT signed (aer-feedback item).
   60: `agent_fingerprint` omitted from the block if session has no agent identity.
   61: 
   62: ## Agent signature (F1)
   63: 
   64: `agent_signature = {fingerprint, public_key, signature}`; `signature` =
   65: base64(Ed25519 over UTF-8 bytes of the entry_hash hex string). Verifier MUST:
   66: 1. fail closed if the session declares no `agent_fingerprint` but an entry
   67:    claims a signature;
   68: 2. recompute fingerprint from embedded `public_key`; require it equal the
   69:    entry's claimed fingerprint AND the session fingerprint AND (when present)
   70:    require embedded key == session `agent_public_key`. NEVER trust the claimed
   71:    fingerprint string;
   72: 3. only then verify the signature over the entry_hash.
   73: 
   74: ## Tri-state verdict (Â§4.3, F2)
   75: 
   76: `authenticated` | `consistent_unattributed` | `failed`.
   77: `anyPresentFailed = !chain_valid || !merkle_valid || org_valid === False ||
   78: agent_valid === False` (None/absent never fails â€” only explicit False).
   79: failed if anyPresentFailed; else authenticated iff org_valid is True; else
   80: consistent_unattributed. `failed` MUST name the failing step. Only
   81: `authenticated` may be called valid.
   82: Note (aer-feedback): in the reference, an absent merkle_root on a populated
   83: log passes; gatehouse's own verifier is stricter for its own bundles (root
   84: required when entries exist) but mirrors reference behavior when verifying
   85: foreign logs.

    1: """E3 â€” domain-separated Merkle root (AER Â§4.2.1, F9).
    2: 
    3: Reproduces the reference demo log's ``merkle_root`` byte-for-byte, proves an
    4: internal node cannot be replayed as a leaf (domain separation), checks the
    5: odd-carry rule on a 3-leaf tree, and pins the empty log to "".

    7: 
    8: from __future__ import annotations
    9: 
   10: import hashlib
   11: import json
   12: 
   13: from gatehouse.merkle import LEAF_PREFIX, NODE_PREFIX, merkle_root
   14: 
   15: from conftest import TS_DEMO_AUDIT_LOG
   16: 
   17: 
   18: def _leaf(h: str) -> bytes:
   19:     return hashlib.sha256(LEAF_PREFIX + bytes.fromhex(h)).digest()
   20: 
   21: 
   22: def _node(left: bytes, right: bytes) -> bytes:
   23:     return hashlib.sha256(NODE_PREFIX + left + right).digest()
   24: 
   25: 
   26: def test_merkle_root_matches_ts_reference():
   27:     log = json.loads(TS_DEMO_AUDIT_LOG.read_text(encoding="utf-8"))
   28:     hashes = [e["entry_hash"] for e in log["entries"]]
   29:     assert merkle_root(hashes) == log["merkle_root"]
   30:     assert merkle_root(hashes) == (
   31:         "a9bbff8d030b54109a855eb8b32a50089bf825902f8be1ada29f4100571ef71f"
   32:     )
   33: 
   34: 
   35: def test_empty_log_root_is_empty_string():
   36:     assert merkle_root([]) == ""
   37: 
   38: 
   39: def test_single_leaf_root_equals_the_leaf():
   40:     h = "a" * 64
   41:     assert merkle_root([h]) == _leaf(h).hex()
   42: 
   43: 
   44: def test_domain_separation_internal_node_cannot_be_replayed_as_leaf():
   45:     # Two leaves -> root is NODE(leaf0, leaf1). If an attacker presents the raw
   46:     # concatenation-hash of the two entry hashes as a single leaf, the domain
   47:     # prefixes (0x00 leaf vs 0x01 node) guarantee it will NOT reproduce the root.
   48:     a, b = "11" * 32, "22" * 32
   49:     root = merkle_root([a, b])
   50:     assert root == _node(_leaf(a), _leaf(b)).hex()
   51: 
   52:     # A forged "leaf" whose value is the internal node digest must not collide.
   53:     internal = _node(_leaf(a), _leaf(b)).hex()
   54:     assert merkle_root([internal]) != root
   55:     # And a leaf hashed WITHOUT domain separation must differ from the real leaf.
   56:     naive_leaf = hashlib.sha256(bytes.fromhex(a)).digest()
   57:     assert naive_leaf != _leaf(a)
   58: 
   59: 
   60: def test_odd_carry_three_leaves_carried_up_unchanged():
   61:     a, b, c = "aa" * 32, "bb" * 32, "cc" * 32
   62:     # Level 1: node(a,b) and c carried up unchanged (NOT duplicated).
   63:     n_ab = _node(_leaf(a), _leaf(b))
   64:     carried = _leaf(c)
   65:     expected = _node(n_ab, carried).hex()
   66:     assert merkle_root([a, b, c]) == expected
   67: 
   68:     # Prove the anti-CVE-2012-2459 property: duplicating the last leaf (the old
   69:     # padding scheme) yields a DIFFERENT root, so the two are not confusable.
   70:     n_cc = _node(_leaf(c), _leaf(c))
   71:     duplicated = _node(n_ab, n_cc).hex()
   72:     assert merkle_root([a, b, c]) != duplicated

  113:     a reroute is a fact the record faithfully carries, not an integrity fault.

  115:     out: list[dict] = []
  116:     for chained in entries:
  117:         if not isinstance(chained, dict):
  118:             continue
  119:         entry = chained.get("entry", {})
  120:         if not isinstance(entry, dict) or entry.get("type") != "model_call":
  121:             continue
  122:         served = entry.get("served_model")
  123:         if served is not None and served != entry.get("model_id"):
  124:             out.append(
  125:                 {
  126:                     "sequence": chained.get("sequence"),
  127:                     "model_id": entry.get("model_id"),
  128:                     "served_model": served,
  129:                 }

  145: def _verify_agent_signatures(
  146:     log: dict[str, Any],
  147: ) -> tuple[bool, Optional[bool], int]:
  148:     """F1-strict per-entry agent signature verification (INTEROP "Agent
  149:     signature"). Returns (present, valid, verified_count).
  150: 
  151:     Fail closed when the session declares no agent fingerprint but an entry
  152:     claims a signature. Recompute the fingerprint from the EMBEDDED public key
  153:     and require it to equal the entry's claimed fingerprint AND the session
  154:     fingerprint AND (when present) the session public key â€” never trust the
  155:     claimed fingerprint string. Only then verify the Ed25519 signature over the
  156:     UTF-8 bytes of the entry_hash hex string.
  157:     """
  158:     session = log.get("session", {})
  159:     session_fp = session.get("agent_fingerprint")
  160:     session_pk = session.get("agent_public_key")
  161:     present = False
  162:     verified = 0
  163: 
  164:     for chained in log.get("entries", []):
  165:         sig = chained.get("agent_signature") if isinstance(chained, dict) else None
  166:         if not sig:
  167:             continue
  168:         present = True
  169:         if not isinstance(sig, dict):
  170:             return True, False, verified
  171: 
  172:         if not session_fp:
  173:             return True, False, verified
  174: 
  175:         try:
  176:             embedded_fp = fingerprint_of(load_public_key_b64(sig.get("public_key")))
  177:         except Exception:
  178:             return True, False, verified
  179: 
  180:         if (
  181:             embedded_fp != sig.get("fingerprint")
  182:             or embedded_fp != session_fp
  183:             or (session_pk is not None and sig.get("public_key") != session_pk)
  184:         ):
  185:             return True, False, verified
  186: 
  187:         try:
  188:             pub = load_public_key_b64(sig.get("public_key"))
  189:         except Exception:
  190:             return True, False, verified
  191: 
  192:         message = str(chained.get("entry_hash", "")).encode("utf-8")
  193:         if not verify_signature(pub, sig.get("signature"), message):
  194:             return True, False, verified
  195: 
  196:         verified += 1
  197: 
  198:     return present, (True if present else None), verified

  201: def _contract_hash_valid(session: dict[str, Any]) -> Optional[bool]:
  202:     """AER Â§4.3 step 6 recompute. Reported for information only â€” the reference
  203:     verifier does not enforce it (feedback #6), and gatehouse mirrors that so a
  204:     redacted derived log (whose contract no longer hashes to the retained
  205:     original value) is not rejected. None when no non-null contract_hash."""
  206:     contract = session.get("intent_contract")
  207:     stored = session.get("contract_hash")
  208:     if not contract or stored is None:
  209:         return None
  210:     return sha256_jcs(contract) == stored

  213: def _core(log: dict[str, Any]) -> dict[str, Any]:
  214:     """The shared verification kernel. Returns the raw pieces both
  215:     ``verify_audit_log`` and ``evidence.build_evidence_record`` project from."""
  216:     entries = log.get("entries", [])
  217:     served = _served_model_mismatches(entries)
  218: 
  219:     if not _is_v2(log):
  220:         return {
  221:             "status": "failed",
  222:             "failing_step": LEGACY_STEP,
  223:             "chain_valid": False,
  224:             "chain_verified_count": 0,
  225:             "merkle_valid": False,
  226:             "org_valid": None,
  227:             "agent_valid": None,
  228:             "agent_verified": 0,
  229:             "contract_hash_valid": None,
  230:             "fully_attributed": None,
  231:             "served": served,
  232:         }
  233: 
  234:     chain_valid, chain_count, chain_detail = verify_chain(entries)
  235: 
  236:     try:
  237:         computed_root = compute_merkle_root(
  238:             [e.get("entry_hash", "") if isinstance(e, dict) else "" for e in entries]
  239:         )
  240:     except Exception:
  241:         # A non-hex entry_hash cannot form a Merkle leaf. The chain check above
  242:         # has already flagged this entry; treat the root as non-recomputing
  243:         # rather than crashing the verifier (Opus review V5a).
  244:         computed_root = None
  245:     log_root = log.get("merkle_root")
  246:     merkle_strict_fail = False
  247:     if entries and not log_root:
  248:         # gatehouse strictness: a populated log MUST carry its Merkle root
  249:         # (reference is lenient here â€” feedback #5).
  250:         merkle_valid = False
  251:         merkle_strict_fail = True
  252:     elif log_root:
  253:         merkle_valid = log_root == computed_root
  254:     else:
  255:         merkle_valid = True  # genuinely empty log
  256: 
  257:     org_valid = _verify_org_signature(log)
  258:     agent_present, agent_valid, agent_verified = _verify_agent_signatures(log)
  259:     session = log.get("session", {}) if isinstance(log.get("session"), dict) else {}
  260:     contract_hash_valid = _contract_hash_valid(session)
  261: 
  262:     # contract_hash is a Â§3.5 MUST. gatehouse ENFORCES it (stricter than the
  263:     # reference â€” feedback #6) for a sealed or agent-signed log, so a full log
  264:     # whose intent_contract was edited without updating the hash fails. A
  265:     # derived_redacted log is exempt: it deliberately retains the ORIGINAL
  266:     # contract_hash while carrying a redacted contract, so a recompute is not
  267:     # expected to match (Opus review V1, partial mitigation â€” the seal still
  268:     # does not cover the contract; see docs/aer-feedback.md #17b).
  269:     contract_enforced = bool(log.get("org_signature")) or agent_present
  270:     contract_fail = contract_enforced and contract_hash_valid is False
  271: 
  272:     # De-attribution signal (Opus review V3): identity declared but not every
  273:     # entry signed.
  274:     session_fp = session.get("agent_fingerprint")
  275:     if not session_fp:
  276:         fully_attributed: Optional[bool] = None
  277:     else:
  278:         signed = sum(
  279:             1 for e in entries if isinstance(e, dict) and e.get("agent_signature")
  280:         )
  281:         fully_attributed = bool(entries) and signed == len(entries)
  282: 
  283:     any_present_failed = (
  284:         not chain_valid
  285:         or not merkle_valid
  286:         or org_valid is False
  287:         or agent_valid is False
  288:         or contract_fail
  289:     )
  290: 
  291:     if any_present_failed:
  292:         status = "failed"
  293:         if not chain_valid:
  294:             failing_step = chain_detail or "hash chain does not verify"
  295:         elif not merkle_valid:
  296:             if merkle_strict_fail:
  297:                 failing_step = (
  298:                     "merkle_root absent on a populated log "
  299:                     "(gatehouse requires merkle_root when entries exist)"
  300:                 )
  301:             else:
  302:                 failing_step = "merkle_root does not recompute"
  303:         elif org_valid is False:
  304:             failing_step = "operator org_signature does not verify"
  305:         elif agent_valid is False:
  306:             failing_step = "agent signature verification failed (F1)"
  307:         else:
  308:             failing_step = (
  309:                 "contract_hash does not match the recomputed intent_contract hash "
  310:                 "(Â§3.5)"
  311:             )
  312:     elif org_valid is True:
  313:         status = "authenticated"
  314:         failing_step = None
  315:     else:
  316:         status = "consistent_unattributed"
  317:         failing_step = None
  318: 
  319:     return {
  320:         "status": status,
  321:         "failing_step": failing_step,
  322:         "chain_valid": chain_valid,
  323:         "chain_verified_count": chain_count,
  324:         "merkle_valid": merkle_valid,
  325:         "org_valid": org_valid,
  326:         "agent_valid": agent_valid,
  327:         "agent_verified": agent_verified,
  328:         "contract_hash_valid": contract_hash_valid,
  329:         "fully_attributed": fully_attributed,
  330:         "served": served,
  331:     }
  332:

  451: def _served_projection_disagreement(
  452:     record: dict[str, Any], entries: list[dict[str, Any]]
  453: ) -> Optional[str]:
  454:     """Record-vs-entry integrity check. An HONEST reroute (served!=requested,
  455:     consistently recorded in BOTH the projection and the chained entry) is fine.
  456:     A disagreement â€” the evidence record's operations projection saying one thing
  457:     about served_model while the chained entry says another â€” IS tampering."""
  458:     ops_by_seq = {op.get("sequence"): op for op in record.get("operations", [])}
  459:     for chained in entries:
  460:         entry = chained.get("entry", {})
  461:         if entry.get("type") != "model_call":
  462:             continue
  463:         seq = chained.get("sequence")
  464:         op = ops_by_seq.get(seq)
  465:         if op is None:
  466:             return f"served_model mismatch between record and chained entry {seq}"
  467:         if op.get("served_model") != entry.get("served_model"):
  468:             return f"served_model mismatch between record and chained entry {seq}"
  469:     return None

  472: def verify_bundle(bundle_dir: Path) -> VerificationReport:
  473:     """Verify an exported bundle end to end: re-hash every file named in the
  474:     manifest against its bytes on disk, verify the manifest operator seal when
  475:     present, verify the embedded ``audit_log.json`` (AER Â§4.3), and cross-check
  476:     the evidence record's served_model projection against the chained entries.
  477:     Any mismatch => ``failed`` with a named step."""
  478:     bundle_dir = Path(bundle_dir)
  479: 
  480:     manifest_path = bundle_dir / "hash_manifest.json"
  481:     audit_log_path = bundle_dir / "audit_log.json"
  482:     record_path = bundle_dir / "evidence_record.json"
  483:     entries_path = bundle_dir / "entries.ndjson"
  484: 
  485:     if not manifest_path.exists():
  486:         return VerificationReport(
  487:             "failed", False, 0, False, None, None, 0, None,
  488:             "hash_manifest.json missing from bundle", [],
  489:         )
  490:     if not audit_log_path.exists():
  491:         return VerificationReport(
  492:             "failed", False, 0, False, None, None, 0, None,
  493:             "audit_log.json missing from bundle", [],
  494:         )
  495: 
  496:     try:
  497:         manifest = _read_json(manifest_path)
  498:         audit_log = _read_json(audit_log_path)
  499:     except (json.JSONDecodeError, OSError, UnicodeDecodeError) as exc:
  500:         return VerificationReport(
  501:             "failed", False, 0, False, None, None, 0, None,
  502:             f"bundle contains unparseable JSON: {type(exc).__name__}", [],
  503:         )
  504:     if not isinstance(manifest, dict):
  505:         return VerificationReport(
  506:             "failed", False, 0, False, None, None, 0, None,
  507:             "hash_manifest.json is not a JSON object", [],
  508:         )
  509: 
  510:     base = verify_audit_log(audit_log)
  511: 
  512:     # (1) File-byte integrity: every file the manifest names must hash to the
  513:     # recorded value (this is what catches a tampered evidence_record.json â€”
  514:     # feedback #4: the reference pair check ignores files{}).
  515:     for name, expected in (manifest.get("files") or {}).items():
  516:         fpath = bundle_dir / name
  517:         if not fpath.exists():
  518:             return _fail(base, f"bundle file {name} listed in manifest is missing")
  519:         actual = sha256_hex(fpath.read_bytes())
  520:         if actual != expected:
  521:             return _fail(base, f"bundle file {name} hash mismatch (tampered)")
  522: 
  523:     # (2) Manifest operator seal (gatehouse seals by default â€” feedback #2).
  524:     seal = _verify_manifest_seal(manifest)
  525:     if seal is False:
  526:         return _fail(base, "manifest operator_signature does not verify")
  527: 
  528:     # (3) Audit-log verdict.
  529:     if base.status == "failed":
  530:         return base
  531: 
  532:     # (4) Full attribution: a gatehouse bundle signs every entry, so a sealed
  533:     # bundle that is not fully attributed has had a signature stripped (Opus
  534:     # review V3). Standalone log verification only surfaces this; the bundle
  535:     # format is gatehouse's own, so here it is a hard failure.
  536:     if base.status == "authenticated" and base.fully_attributed is False:
  537:         return _fail(
  538:             base,
  539:             f"partial attribution: {base.agent_verified_count} of "
  540:             f"{len(audit_log.get('entries', []))} entries signed "
  541:             "(an agent signature was stripped from a sealed bundle)",
  542:         )
  543: 
  544:     # (5) served_model record-vs-entry integrity (E8).
  545:     if record_path.exists() and entries_path.exists():
  546:         try:
  547:             record = _read_json(record_path)
  548:             entries = _read_ndjson(entries_path)
  549:         except (json.JSONDecodeError, OSError, UnicodeDecodeError) as exc:
  550:             return _fail(base, f"bundle payload unparseable: {type(exc).__name__}")
  551:         step = _served_projection_disagreement(record, entries)
  552:         if step is not None:
  553:             return _fail(base, step)
  554: 
  555:     return base

  558: def verify_pair(redacted_dir: Path, original_log_path: Path) -> VerificationReport:
  559:     """Confirm a redacted bundle is a FAITHFUL derivation of a sealed original
  560:     (AER Â§5, F3). Given the redacted bundle's manifest + derived entries and the
  561:     original log, check per entry that derived-n binds to source-n, that nothing
  562:     was dropped/reordered/substituted, that the derived chain self-verifies, and
  563:     that the manifest's source/derived tips are correct."""
  564:     redacted_dir = Path(redacted_dir)
  565: 
  566:     def failed(step: str, chain_valid: bool = False, chain_count: int = 0) -> VerificationReport:
  567:         return VerificationReport(
  568:             "failed", chain_valid, chain_count, False, None, None, 0, None, step, [],
  569:         )
  570: 
  571:     try:
  572:         manifest = _read_json(redacted_dir / "hash_manifest.json")
  573:         derived = _read_ndjson(redacted_dir / "entries.ndjson")
  574:         original = _read_json(Path(original_log_path))
  575:     except (json.JSONDecodeError, OSError, UnicodeDecodeError) as exc:
  576:         return failed(f"pair inputs unreadable: {type(exc).__name__}")
  577:     if not isinstance(manifest, dict) or not isinstance(original, dict):
  578:         return failed("manifest or original is not a JSON object")
  579: 
  580:     # A "faithful derivation" claim is only meaningful against an AUTHENTIC
  581:     # original. Verify the original first; refuse to certify a binding to a
  582:     # document that does not itself verify (Opus review V4). An unsigned but
  583:     # internally-consistent original (consistent_unattributed) is an acceptable
  584:     # source; only a FAILED original is refused.
  585:     original_report = verify_audit_log(original)
  586:     if original_report.status == "failed":
  587:         return failed(
  588:             f"original log does not verify ({original_report.failing_step}); "
  589:             "cannot certify a redaction binding against a non-authentic original"
  590:         )
  591: 
  592:     source_hashes = [
  593:         e.get("entry_hash") for e in original.get("entries", []) if isinstance(e, dict)
  594:     ]
  595:     source_count = len(source_hashes)
  596:     derived_count = len(derived)
  597:     served = _served_model_mismatches(derived)
  598: 
  599:     if manifest.get("bundle_kind") != "derived_redacted":
  600:         return failed(
  601:             f'manifest.bundle_kind is "{manifest.get("bundle_kind")}", '
  602:             'expected "derived_redacted"'
  603:         )
  604: 
  605:     if manifest.get("source_entry_count") != source_count:
  606:         return failed(
  607:             f"manifest.source_entry_count ({manifest.get('source_entry_count')}) "
  608:             f"!= original entry count ({source_count})"
  609:         )
  610: 
  611:     manifest_sources = manifest.get("source_entry_hashes")
  612:     if not isinstance(manifest_sources, list):
  613:         return failed("manifest.source_entry_hashes is missing or not an array")
  614:     if len(manifest_sources) != source_count:
  615:         return failed(
  616:             f"manifest.source_entry_hashes length ({len(manifest_sources)}) "
  617:             f"!= original entry count ({source_count})"
  618:         )
  619:     for i in range(source_count):
  620:         if manifest_sources[i] != source_hashes[i]:
  621:             return failed(
  622:                 f"manifest.source_entry_hashes[{i}] does not match the original entry hash"
  623:             )
  624: 
  625:     if derived_count != source_count:
  626:         return failed(
  627:             f"derived entry count ({derived_count}) != source entry count "
  628:             f"({source_count}) - entries dropped or added"
  629:         )
  630: 
  631:     # Per-entry binding: derived-n names source-n.
  632:     for i in range(source_count):
  633:         bound = derived[i].get("source_entry_hash")
  634:         if bound is None:
  635:             return failed(f"derived entry {i} has no source_entry_hash - not bound")
  636:         if bound != source_hashes[i]:
  637:             return failed(
  638:                 f"derived entry {i} binds to the wrong source entry - reordered or substituted"

    1: """Domain-separated Merkle root, AER v0.1 Â§4.2.1 (red-team F9).
    2:

    9: evidence/conformance/probe_golden_output.txt line 2.

   13: 
   14: import hashlib
   15: from collections.abc import Sequence
   16:

   19:

   22: 
   23: def merkle_root(entry_hashes: Sequence[str]) -> str:
   24:     """Merkle root (lowercase hex) over ordered entry_hash hex strings."""
   25:     if not entry_hashes:
   26:         return ""
   27:     level = [
   28:         hashlib.sha256(LEAF_PREFIX + bytes.fromhex(h)).digest()
   29:         for h in entry_hashes
   30:     ]
   31:     while len(level) > 1:
   32:         nxt = []
   33:         for i in range(0, len(level) - 1, 2):
   34:             nxt.append(

   36:             )
   37:         if len(level) % 2 == 1:
